Cryonix Launcher is a modern, lightweight Minecraft launcher for Android designed with a clean and smooth user interface inspired by next-generation launcher experiences like Feather-style UI design.
It focuses on performance, simplicity, and customization, giving users an easy way to manage and launch different Minecraft versions with a fast and responsive interface.
✨ Features
🎮 Modern launcher UI with dark + neon/rainbow styling
📦 Minecraft version selector system
⚡ Fast and lightweight performance
⚙️ Settings panel for customization
👤 Simple offline profile system
📁 JSON-based version management
🔄 Modular and expandable architecture
